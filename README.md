## 🎯 Aim
Solving real world problems through **Python-MySQL connectivity** involving **database operations (CRUD)**, and helping students in practical exams and self-learning.

---

## 📌 Project Description
This project includes simple Python programs that show how to:
- Connect Python to MySQL
- Create database tables
- Insert, retrieve, update, and delete records

---

## 🛠 Technologies Used
- Python 3
- MySQL Server
- mysql-connector-python

---

## 📂 Project Structure

```
python-mysql-connectivity/ │
├── connect.py # MySQL connection
├── create_table.py # Table creation
├── insert_data.py # Insert records
├── read_data.py # Fetch records
├── update_data.py # Update records
├── delete_data.py # Delete records ├──
```
